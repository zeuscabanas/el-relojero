# El relojero

Un caballero de cuerda en un garaje dormido. Demo de un juego de plataformas en 2D hecho con three.js.

**Jugar:** https://zeuscabanas.github.io/el-relojero/

Controles (se pueden cambiar en Ajustes → Controles): A/D o flechas para moverse, Espacio para saltar, J golpear, K guardia, Mayús impulso, E usar, Q aceite, M mapa, Esc pausa.

Para probarlo en local hace falta servir la carpeta (no funciona abriendo el HTML con doble clic):

    python -m http.server
    # y abrir http://localhost:8000
